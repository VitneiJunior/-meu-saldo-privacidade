# Política de Privacidade — Meu Saldo

**Última atualização:** 7 de novembro de 2026  
**Desenvolvedor:** V.A.J Solutions  
**Contato:** vitneijr@gmail.com

## 1. Finalidade
O Meu Saldo é um aplicativo de organização financeira pessoal para registrar receitas, despesas, parcelas, lançamentos recorrentes, categorias, orçamentos e preferências.

## 2. Dados tratados
Os dados que o usuário insere no aplicativo podem incluir descrições de lançamentos, valores, datas, categorias, observações e nome de exibição. Esses dados são armazenados no banco de dados local do dispositivo. O aplicativo também guarda preferências de interface e segurança.

## 3. Backup e transferência
O usuário pode criar backups manualmente e escolher compartilhar os arquivos por outros aplicativos. O arquivo de backup pode conter dados financeiros e preferências, portanto deve ser armazenado em local seguro. O sistema Android também pode efetuar backup e transferência de dados do aplicativo, conforme as configurações do aparelho e os serviços do sistema. O backup manual contém verificação de integridade, mas não deve ser considerado criptografado.

## 4. Biometria e segurança
Quando habilitado, o bloqueio do aplicativo utiliza a autenticação biométrica ou credenciais seguras do Android. O aplicativo não armazena imagens de impressões digitais. Há opções para ocultar valores e proteger a visualização em capturas de tela.

## 5. Compartilhamento
O compartilhamento de arquivos de backup ocorre quando o usuário aciona essa funcionalidade. Serviços externos escolhidos pelo usuário para receber ou guardar esses arquivos possuem suas próprias políticas de privacidade.

## 6. Retenção e exclusão
Os dados locais permanecem no dispositivo até serem excluídos pelo usuário, por meio dos recursos do aplicativo ou da limpeza dos dados nas configurações do Android. Arquivos de backup salvos em Downloads ou enviados para outros serviços precisam ser excluídos separadamente.

## 7. Direitos e contato
Para dúvidas sobre privacidade ou tratamento de dados, escreva para **vitneijr@gmail.com**.

## 8. Atualizações
Esta política poderá ser atualizada para refletir alterações no aplicativo e em suas funcionalidades.
